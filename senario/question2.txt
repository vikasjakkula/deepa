JAVA OOP ASSESSMENT 
Level–2: Moderate Complexity 
Problem Statement 
ShopZone is an online shopping application that manages different types of products such as 
electronic items, grocery items, and clothing products. The application should maintain 
product information, allow customers to search and select products, manage shopping cart 
items, calculate discounts, and generate the final bill. 
Develop a Java application for ShopZone that models the requirements described below. 
1. Manufacturer Management 
Each product sold through ShopZone is associated with a manufacturer. 
For every manufacturer, the application should maintain: 
• Manufacturer name 
• Country of origin 
The application should be able to create manufacturer information and display it whenever 
required along with the corresponding product details. 
The following manufacturers should be considered: 
• Samsung – South Korea 
• Apple – USA 
• Nestle – Switzerland 
• Nike – USA 
2. Product Management 
ShopZone should maintain common information for every product: 
• Product ID 
• Product name 
• Price 
• Available quantity 
• Manufacturer details 
The application should be able to: 
• Create products with the required information. 
• Display complete product details. 
• Calculate the total value of a particular product based on its price and quantity. 
• Modify the quantity of a product whenever required. 
• Compare products based on their product ID. 
• Display product information in a readable format. 
Two product objects having the same product ID should be treated as representing the same 
product. 
3. Electronic Products 
ShopZone sells electronic products. 
For every electronic product, maintain: 
• Product ID 
• Product name 
• Price 
• Quantity 
• Manufacturer 
• Warranty period in months 
Electronic products receive a 10% discount. 
Some electronic products also provide Bluetooth support. The application should be able to 
display a suitable message when Bluetooth functionality is requested for such a product. 
Create the following electronic products: 
Laptop 
• Product ID: 101 
• Name: Laptop 
• Price: Rs.60,000 
• Quantity: 1 
• Manufacturer: Samsung 
• Warranty: 24 months 
Bluetooth Headphones 
• Product ID: 102 
• Name: Bluetooth Headphones 
• Price: Rs.3,000 
• Quantity: 2 
• Manufacturer: Apple 
• Warranty: 12 months 
• Bluetooth support: Available 
4. Grocery Products 
ShopZone also sells grocery products. 
For every grocery product, maintain: 
• Product ID 
• Product name 
• Price 
• Quantity 
• Manufacturer 
• Expiry date 
The application should be able to display the expiry information of a grocery product. 
Grocery products do not receive a discount. 
Create the following grocery product: 
Rice 
• Product ID: 103 
• Name: Rice 
• Price: Rs.800 
• Quantity: 2 
• Manufacturer: Nestle 
• Expiry date: 31-12-2026 
5. Clothing Products 
ShopZone sells clothing and related products. 
For every clothing product, maintain: 
• Product ID 
• Product name 
• Price 
• Quantity 
• Manufacturer 
• Size 
Clothing products receive a 15% discount. 
Create the following clothing product: 
Sports Shoes 
• Product ID: 104 
• Name: Sports Shoes 
• Price: Rs.4,000 
• Quantity: 1 
• Manufacturer: Nike 
• Size: 9 
6. Product Collection 
ShopZone should maintain all available products in the system. 
The application should provide the following operations: 
Add Product 
Add a newly created product to the available product list. 
Display Products 
Display all products currently available in ShopZone. 
The information should include the product ID, name, price, quantity, and any additional 
information applicable to that product. 
Find Product 
Search for a product using its product ID. 
If the product exists, display or return its details. If it does not exist, the operation should 
indicate that the product was not found. 
Search by Name 
Allow the user to search for products using their names. 
The search should not depend on whether the entered name is written in uppercase or 
lowercase. 
For example, searches for: 
Laptop 
laptop 
LAPTOP 
should be able to identify the Laptop product. 
Product Statistics 
Display: 
• Number of products available 
• Total value of all available products 
The total value should consider the quantity available for every product. 
7. Shopping Cart 
ShopZone should provide a shopping cart where customers can add products they wish to 
purchase. 
The cart should allow a product to be added: 
• Using its existing quantity 
• By specifying a particular quantity 
The cart should display all selected products along with their quantities. 
8. Handling Repeated Products 
If a customer adds a product that is already present in the cart, the application should not 
display it as a separate cart entry. 
Instead, the newly added quantity should be added to the existing quantity. 
For example, if the cart already contains: 
Bluetooth Headphones – Quantity: 2 
and the customer adds: 
Bluetooth Headphones – Quantity: 1 
the cart should finally contain: 
Bluetooth Headphones – Quantity: 3 
9. Discount Calculation 
The application should calculate the amount payable for each product based on its price and 
quantity. 
The applicable discounts are: 
Product Type 
Discount 
Electronic Product 10% 
Grocery Product No discount 
Clothing Product 15% 
The discount should be calculated according to the quantity purchased. 
For example, if the customer purchases one Laptop for Rs.60,000, the discount should be 
Rs.6,000 and the amount payable should be Rs.54,000. 
10. Bill Generation 
The shopping cart should generate a bill containing: 
• Product name 
• Amount payable for each product 
• Subtotal before discounts 
• Total discount 
• Final amount payable 
For the products and quantities specified above, after adding one additional Bluetooth 
Headphones item to the cart, the final quantities should be:

1 
The application should calculate the final bill accordingly. 
11. Product Search and Selection 
The application should demonstrate searching for a product and displaying the matching 
product information. 
For example, searching for: 
Laptop 
should display the details of the Laptop available in ShopZone. 
The application should also demonstrate retrieving products using their unique product IDs. 
12. Product-Specific Operations 
The application should provide operations that are applicable only to particular types of 
products. 
For example: 
• Electronic products that provide Bluetooth functionality should be able to display 
their Bluetooth support. 
• Grocery products should be able to display their expiry information. 
• Products eligible for discounts should have their applicable discount considered 
during bill generation. 
The main application should demonstrate these operations using the products created 
earlier. 
13. Product Copy 
The ShopZone application should support creating a separate copy of an existing product. 
Create a copy of the Sports Shoes product. 
Initially, both the original and copied product should contain: 
Quantity: 1 
Change the quantity of the copied product to: 
Quantity: 3 
After the change, display both products. 
The output should demonstrate that changing the copied product does not change the 
quantity of the original product. 
Expected situation: 
Original Sports Shoes → Quantity: 1 
Copied Sports Shoes   → Quantity: 3 
14. Main Application 
Create a main program that performs the following sequence: 
1. Create the manufacturer information. 
2. Create the four products. 
3. Add all products to the ShopZone product collection. 
4. Display all available products. 
5. Search for the Laptop by name. 
6. Display the calculated value of each product based on its quantity. 
7. Display Bluetooth information for the Bluetooth Headphones. 
8. Display expiry information for Rice. 
9. Display product statistics. 
10. Create a shopping cart. 
11. Add all four products to the cart. 
12. Add one additional Bluetooth Headphones item. 
13. Display the updated cart. 
14. Generate the bill. 
15. Create a separate copy of Sports Shoes. 
16. Change the quantity of the copied product to 3. 
17. Display the original and copied products to verify that they maintain independent 
quantities.
